# Проект: Управление товарами и категориями (Интернет-магазин)

## 📌 Описание проекта

Проект представляет собой базовую реализацию структуры интернет-магазина на Python с использованием объектно-ориентированного подхода.

В проекте реализованы классы:

- **`Product`** — описывает товар с его характеристиками
- **`Category`** — описывает категорию товаров и управляет списком товаров в ней
- **`Smartphone`** — наследник `Product`, описывает смартфон с дополнительными характеристиками
- **`LawnGrass`** — наследник `Product`, описывает газонную траву с дополнительными характеристиками

Проект демонстрирует:
- создание классов и объектов
- наследование
- использование атрибутов класса и экземпляра
- инкапсуляцию (приватные атрибуты)
- автоматический подсчёт количества категорий и товаров
- строковое представление объектов (`__str__`, `__repr__`)
- магический метод сложения (`__add__`) с защитой от сложения разных классов
- защиту метода `add_product` от добавления неправильных типов
- тестирование с использованием `pytest` (покрытие > 90%)

## 🧱 Классы и их возможности

### `Product`
Представляет товар.  
**Атрибуты:**
- `name` — название (строка)
- `description` — описание (строка)
- `price` — цена (float) — приватный, доступ через `@property`
- `quantity` — количество в наличии (int)

**Методы:**
- `__str__` — строковое представление: `Название, X руб. Остаток: X шт.`
- `__repr__` — представление для списков (такое же, как `__str__`)
- `__add__` — сложение товаров (общая стоимость на складе). Работает только для одинаковых классов.
- `new_product` — класс-метод для создания товара из словаря

**Пример создания:**
```python
product = Product("Ноутбук", "Игровой", 100000, 10)
print(product)  # Ноутбук, 100000 руб. Остаток: 10 шт.
